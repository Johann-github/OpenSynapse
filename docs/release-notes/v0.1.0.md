First preview of OpenSynapse for Windows: a small, local-first tool to configure Razer mice
without Razer Synapse. No account, no cloud, no telemetry.

**Preview quality.** Hardware-tested with one device: the **Razer Viper V3 HyperSpeed**
(wireless dongle). Other Razer mice with protocol 2.5 may work. Before writing to a device that
has not been tested, OpenSynapse prints a warning (CLI) or shows one (GUI). Reading is always safe.

## Download
`OpenSynapse-v0.1.0-windows-x64.zip` (Windows 10/11, x64). Checksum: the `.sha256` file next
to it. Built on GitHub Actions from tag `v0.1.0`.

## Install
1. Close Razer Synapse.
2. Unzip, then run `opensynapse.exe install` in that folder. It installs to
   `%LOCALAPPDATA%\Programs\OpenSynapse` (no admin rights), adds **OpenSynapse** to the
   Start menu, and starts the background agent now and at login.
3. Open **OpenSynapse** from the Start menu.

Uninstall: `opensynapse uninstall` (your settings in `%APPDATA%\OpenSynapse` are kept).

## What works
- GUI, CLI and a background agent (~9 MB RAM, ~0 % CPU when idle).
- DPI and DPI stages, polling rate (125/500/1000 Hz), sleep timer.
- Button assignments stored on the mouse: mouse button, key (with modifiers), double-click,
  DPI up/down, off. They keep working without OpenSynapse.
- Per-app profiles: settings change when a chosen program gets focus, and change back after.
- Battery level, updated live from the mouse's own battery event.
- Profiles as TOML: export, apply (dry run first), automatic restore file.
- Every CLI write is a dry run unless you add `--apply`; values are read back after writing.

## Known limitations
- **Not code-signed**: Windows SmartScreen may warn on first start ("More info" → "Run anyway").
- Only the Viper V3 HyperSpeed is hardware-tested (see above).
- No lighting/RGB and no macros yet. OpenSynapse never updates firmware.
- Do not run it together with Razer Synapse; both talk to the same device.
- Linux and macOS: in progress on branch `linux-macos-port` (builds and tests pass in CI,
  not yet tried on real hardware).

## Privacy
OpenSynapse makes no network connections. Config is plain TOML in `%APPDATA%\OpenSynapse`.
